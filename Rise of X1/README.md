# Rise of X1

## Game Description

*Rise of X1* is a top-down, progression-based survival game where the player controls an evolving organism navigating a hostile underwater environment. The player must defeat enemies, collect DNA fragments, and survive increasingly dangerous encounters while unlocking new abilities.

The core gameplay loop consists of:
- Waves of enemies 
- Fighting enemies using ranged and melee attacks
- Collecting DNA dropped from enemies
- Avoiding too much damage from enemies

---

## Game Instructions

### Controls
- **W / A / S / D** – Move character
- **Mouse** – Aim
- **Left Click** – Shoot projectile
- **Right Click** – Melee attack
- **Shift** – Dash (if unlocked)
- **E** - Burst attacked (if unlocked)


---

### Objective
- Defeat enemies to collect DNA
- Use DNA to evolve new abilities
- Progress through the levels
- Defeat the Kraken boss

---

### Core Mechanics
- **Ranged Combat:** Shoot projectiles toward the cursor
- **Melee Combat:** Short-range attack with cooldown
- **Enemy Types:**
  - Basic melee enemies
  - Basic ranged enemies
  - Dash enemies
  - Damage-over-time (parasite) enemies
- **DNA Drops:** Enemies drop DNA used for progression/upgrades
- **Health System:** Player takes damage from enemies and dies at 0 HP
- **Extra Life:** Passive enemy that will randomly appear and grants an extra life if collected

---

## Game Walkthrough

1. **Start Game**
   - Player spawns in the initial room

2. **Combat Basics**
   - Use ranged attacks to safely eliminate enemies
   - Use melee when enemies get close
   - Moving frequently makes avoiding enemy damage easier

3. **Enemy Encounters**
   - Some enemies charge or lunge toward the player
   - Enemy abilities and level difficulties scale with progress
   - Maintain distance and reposition frequently

4. **DNA Collection**
   - Defeated enemies drop DNA strands
   - Collect them to progress toward upgrades
   - Upgrades make aspects like combat, movement, and progression easier
   - Consider stocking up before the boss fight

5. **Survival Strategy**
   - Avoid getting surrounded
   - Use movement to kite enemies
   - Prioritize dangerous enemies first

6. **Progression and End Game**
   - If player HP reaches 0 and player has no extra lives, the game ends
   - Defeating all enemies in a level progresses the player to the next level
   - Defeat the Kraken boss in the last level to win the game

## Cheat Codes (For Testing / Presentation)

- **F1** – Toggle God Mode (infinite HP)
- **F2** – Unlock all abilities
- **F3** – Clear all enemies in room
- **F4** – Reset player position

- **CTRL + 1** - Add Mantis DNA
- **CTRL + 2** - Add Dart DNA
- **CTRL + 3** - Add Crab DNA
- **CTRL + 4** - Add Witch DNA
- **CTRL + 5** - Add Mote DNA
- **CTRL + 6** - Collect Eternal Hydras (extra life)
- **CTRL + 7** - Go to room start
- **CTRL + 8** - Go to room main
- **CTRL + 9** - Go to room win
- **CTRL + 0** - Go to room lose

- **B** - Skips time to Kraken Battle
